# Service icons

These assets are bundled locally so service cards and linked files do not depend on third-party image requests at runtime.

- Microsoft 365 / Office, Word, Excel: Microsoft product SVGs from `https://static2.sharepointonline.com/files/fabric/assets/brand-icons/product/svg/{office,word,excel}_48x1.svg`.
- Google Drive: `https://ssl.gstatic.com/images/branding/product/2x/drive_2020q4_48dp.png`.
- Google Forms: `https://www.gstatic.com/images/branding/product/2x/forms_2020q4_48dp.png`.
- Canva: `https://static.canva.com/static/images/apple-touch-120x120.png`.
- Asana and Trello: SVG paths from the [Simple Icons project](https://github.com/simple-icons/simple-icons), colored with the respective brand colors. Simple Icons distributes icons under CC0; service marks remain the property of their respective owners.
